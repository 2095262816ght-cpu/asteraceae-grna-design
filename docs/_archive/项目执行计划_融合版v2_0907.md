## 一、总体策略（一句话）

**保留"首个菊科通用 gRNA 设计工具"的竞赛叙事，核心引擎换为"公开预训练模型 + 自有橡胶草 Hi-TOM 实测数据微调/Stacking"，莴苣作为参考与演示对象，多组学（表观）降级为可选加分项，在线工具用 Streamlit/Gradio 轻量实现。**

## 三、分阶段计划

### 阶段 0：收尾数据盘点 + 环境就绪（9月7日–9月8日，2 天）

第 0 步（9.3–9.6）应已完成大部分，本阶段收尾并补缺：

- [ ] 确认自有 Hi-TOM 数据表定稿：gRNA 序列、基因组坐标、PAM、批次、归一化效率标签齐全；总条数、批次数统计完毕
- [ ] 确认每条 gRNA 可取到 30 bp 上下文 + PAM（模型输入格式要求）
- [ ] 批次质控图（各批次效率分布箱线图）已出，批次内归一化已做
- [ ] **路线预判**（不等 M2 正式结论）：数据量 <100 条 → 心理预期走 Stacking；≥几百条 → 心理预期走微调
- [ ] conda 环境建好；DeepSpCas9（优先 crisprScore R 包或 genet Python 封装）开始部署
- [ ] 并行：从 LettuceGDB 下载莴苣参考基因组 + 注释 + 染色质可及性图谱（已确认公开可得）；从 AGRP（asteraceae.cgrpoee.top）登记向日葵等菊科基因组备用

产出：干净数据表 + 可用环境 + 莴苣基因组数据落盘。

### 阶段 1：模型复现 + 迁移可行性验证（9月8日–9月10日，3 天）

**9月8日–9日：复现**
- [ ] 下载 DeepSpCas9 Table S1（12,832 条训练数据）
- [ ] 跑通 DeepSpCas9，用论文自带测试集验证指标大致吻合（不追求论文级复现，**拒绝环境地狱**，卡住超半天就换封装或换模型）
- [ ] 部署 CRISPRon（github.com/RTH-tools/crispron）
- [ ] 时间允许则加试 CRISPR-AIDIT / CRISPR_HNN（候选清单见可行性报告，不追新榜单）

**9月9日–10日：迁移可行性验证（M2 决策点）**
- [ ] 各预训练模型给全部自有 gRNA 打分，与 Hi-TOM 实测效率算 Spearman ρ，画散点图

决策规则（提前定死，不临场改）：

| 实测 ρ | 路线 |
|---|---|
| > 0.4 | 迁移基础好 → 主线微调（阶段 2-A） |
| 0.2 ~ 0.4 | 微调 + Stacking 并行试 |
| < 0.2 | 跳微调，Stacking 优先，直接进入阶段 3 评估 |

产出：迁移性评估报告（每个模型 ρ + 散点图）+ 书面路线决定。**这是全项目最重要的决策点，务必在 9月10日当天出结论。**

### 阶段 2：双线并行（9月10日–9月21日，约 1.5 周）

#### 2-A 迁移训练（核心，对齐原大纲第 3 步）

微调主线：
- [ ] 加载预训练权重，冻结卷积层只训全连接层，小学习率
- [ ] **按基因/靶区域分组划分训练测试集**（防数据泄漏，这是评审会查的点）
- [ ] 需要时：公开数据加权混合训练（自有数据高权重）

Stacking 备选（数据少或 ρ 低时启用）：
- [ ] 多个预训练模型打分作为特征，自有数据训练顶层岭回归（照 Chen2022 ensemble_ridge 方案）

#### 2-B 菊科工具骨架（对齐新方案模块一/二的可做部分）

- [ ] gRNA 扫描脚本：枚举莴苣基因组（启动子 + 外显子区域）所有 NGG PAM 上游 20nt 候选（纯编程，1~2 天）
- [ ] 同源映射管线：BLAST 直系同源基因查找，"定位同源基因 → 在新物种序列上重扫 gRNA → 模型打分"（主路径，只依赖纯序列模型，科学上成立）
- [ ] Cas-OFFinder 本地跑通，输入基因组 + gRNA 出脱靶位点
- [ ] 9月14日（M2.5）：莴苣 → 向日葵（或 AGRP 上另一菊科）完整走通一次端到端流程

#### 2-C（可选，不排专人死线）多组学探索

- [ ] 莴苣 ATAC-seq 特征提取：候选 gRNA 是否落在开放区域，作为模型的附加特征试一把（只在 2-A 顺利时做）
- [ ] 核实莴苣 ChIP-seq 可得性，不可得即砍（1 天内出结论）
- [ ] 探索：a2z（Wrightsman 2022）公开模型直接给菊科序列预测染色质开放性，或按 SeiPlant 思路做菊苣族级联合训练——**只做"组成型开放"粗粒度推断，不承诺组织特异性**；做不出来不影响主线，做出来是"族内迁移"叙事强加分

产出（M3，9月21日）：迁移模型初版指标 + 工具骨架可跑。

### 阶段 3：评估达标 + demo 成型（9月21日–9月27日，1 周）

评估标准（定死）：**独立测试集 Spearman ρ ≥ 0.5 视为可用。**

- 达标 → 冻结模型，转入固化
- 不达标 → 按优先级扩充（对齐原大纲第 4 步）：
  1. Chen2022 汇总的公开数据集（Doench2016/Azimuth、Chari_293T、XuHL60、Achilles/DepMap 等）加权混合再训练
  2. 伪标注：预训练模型给橡胶草基因组候选 gRNA 批量打分 → 伪标注预训练 + 真实数据微调
  3. 标签在测序误差范围内噪声扰动小幅扩增
  - **禁止**：改序列保留标签的"假扩增"；小数据下用 GAN/VAE 生成数据

工具侧：
- [ ] Streamlit/Gradio demo：输入基因名/粘贴序列/上传基因组 → 输出 gRNA 序列 + 效率评分 + 脱靶风险（1~2 天可出，赛期内不做 Flask/Django 全栈——全基因组扫描和 Cas-OFFinder 是分钟级以上的长任务，真在线服务需要任务队列 + 异步架构 + 持续运维，成本不在写代码而在调试和部署；全栈版本留作晋级后的升级项，见阶段 5）
- [ ] 用向日葵等第二菊科物种公开数据做端到端演示测试
- [ ] 若实验条件允许：启动模型推荐高分 gRNA 的 Hi-TOM 湿实验验证（闭环验证是答辩最大亮点；来不及则写入报告"后续计划"，晋级后 10月13日前补）

产出（M4，9月27日）：达标模型 + 可录屏的 demo。
