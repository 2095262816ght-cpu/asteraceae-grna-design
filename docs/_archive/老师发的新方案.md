# 研究方案：基于多组学数据迁移学习的菊科植物通用 gRNA 设计工具

## 1. 研究目标

开发一款在线工具，其核心预测模型基于莴苣（作为菊科模式植物）的高质量基因组、表观基因组和转录组数据训练，并能通过迁移学习策略，支持用户上传任意菊科物种的基因组序列，进行 gRNA 效率和脱靶风险的跨物种预测。

## 2. 核心科学问题

- 如何将莴苣中由多组学数据定义的"功能性 gRNA 靶点"（如位于开放染色质、活跃启动子区域的位点）特征，有效地迁移到其他菊科物种的基因组上？
- 如何设计算法，使之既能利用莴苣数据的**深度**（多组学信息），又能利用用户提供序列的**广度**（跨物种），实现准确的 gRNA 评分？

## 3. 总体技术路线

本方案将采用"**模式物种精调 + 跨物种映射**"的混合策略，具体分为三个模块：

1. **模块一：莴苣核心预测模型的构建**——基于莴苣的多组学数据，训练一个 gRNA 效率与特异性预测的基础模型。
2. **模块二：跨物种知识迁移引擎**——开发一个映射层，将用户输入的基因组序列与莴苣参考基因组进行比对，并基于同源性和序列保守性，将模块一的预测结果迁移到目标序列上。
3. **模块三：在线工具的前后端开发**——搭建用户友好的网页界面，集成上述功能。

## 4. 具体实施步骤

### 第一阶段：数据整合与莴苣核心模型训练（第 1–10 天）

#### 1. 多组学数据获取与处理

- **参考基因组与注释**：从 LettuceGDB 下载高质量的莴苣参考基因组及基因注释文件。
- **表观基因组数据**：获取莴苣的染色质可及性数据（ATAC-seq），它定义了开放染色质区域，是 gRNA 能否有效结合的关键。同时，若能获得特定组蛋白修饰的 ChIP-seq 数据（如 H3K4me3、H3K27ac）将更佳，这有助于精确定位活跃的启动子和增强子区域。
- **转录组数据**：获取莴苣不同组织或条件下的转录组数据（RNA-seq），用于评估基因的表达水平。

#### 2. 核心预测模型构建

- **gRNA 扫描**：开发脚本，在莴苣的基因区域（尤其是启动子、外显子区域）扫描所有潜在的 gRNA 靶点（如 SpCas9 识别的"NGG"PAM 序列）。
- **效率与脱靶特征提取**：为每个候选 gRNA 提取特征，包括：
  - **序列特征**：GC 含量、是否富含特定核苷酸等。
  - **表观特征**：靶点是否位于 ATAC-seq 定义的开放染色质区域；是否落在特定组蛋白修饰标记的活性区域。
  - **转录特征**：靶向基因的表达水平。
- **模型训练**：基于上述特征，使用机器学习方法（如 GNL-Scorer 采用的贝叶斯岭回归，或更复杂的深度学习模型），在莴苣的已知 gRNA 活性数据集（如能获取）或通过实验验证的少量数据上，训练一个 gRNA 效率评分模型。若缺少训练数据，可先采用如 CRISPRscan 等已有的、适用于植物的评分规则作为基线。

### 第二阶段：跨物种预测引擎开发（第 11–18 天）

#### 1. 同源序列映射

当用户上传一个非莴苣的菊科物种基因组序列后，工具首先通过序列比对，在用户序列中寻找与莴苣基因组中已知基因同源的区域。

#### 2. 知识迁移策略

- **直接同源映射**：如果找到了直系同源基因，优先将莴苣模型中该基因附近的高评分 gRNA 位点，通过序列比对"投影"到新物种的对应位置。这是一个非常精准的策略。
- **特征空间映射**：对于没有明确同源关系的区域，工具则基于序列特征（如 GC 含量）和表观特征推断（如预测染色质开放区域），来评估 gRNA 的潜在效率。此时，莴苣模型学到的"权重"（例如，开放染色质比封闭染色质对效率的贡献高 20%）将被直接应用。

### 第三阶段：在线工具开发与部署（第 19–25 天）

1. **前后端开发**：使用 Flask/Django 等框架搭建后端，负责运行核心算法；前端提供简洁的用户界面，允许用户输入基因名或粘贴序列、上传基因组文件，并清晰展示结果（gRNA 序列、效率评分、脱靶风险）。
2. **脱靶预测集成**：集成成熟的脱靶预测算法，如 Cas-OFFinder，对新物种基因组进行全面的潜在脱靶位点搜索。
3. **测试与部署**：使用莴苣及另一种菊科植物（如向日葵）的公开数据进行测试，验证跨物种预测的准确性。部署到服务器，对外提供服务。

## 5. 方案优势与创新点

- **开创性**：这是首个专注于菊科植物、并明确采用"模式植物数据驱动跨物种预测"策略的 gRNA 设计工具。
- **实用性**：它解决了非模式菊科植物研究人员缺乏高效 gRNA 设计工具的痛点。
- **科学性**：该研究将系统评估表观基因组和转录组信息在跨物种 gRNA 效率预测中的价值，具有重要的科学意义。
