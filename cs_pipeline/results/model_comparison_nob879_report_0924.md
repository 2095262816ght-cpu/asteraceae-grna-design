## 二、可比性告警（引用本表前必读）

1. **测试集有效样本极小，p 值系统性过度乐观**：留出集 198 行，但只覆盖 **4 个基因组 / 7 条 distinct seq30**。同一 guide 的重复测定不提供新的序列-效率信息，故 ρ 与 AUC 的有效样本量是 7 而不是 198；而 `spearman_p_test` 是按 n=198 计自由度的，**不得单独引用**——表中已并列给出去重口径（按 distinct guide 取 indel 中位数后重算的 `spearman_rho_test_dedup` / `spearman_p_test_dedup`）。这与 D2 决策点当年 ρ=0.331（p=4.67e-8）被自查撤回是同一个伪重复陷阱（见 `transferability_D2_0912.md` 第〇节），也与方案2 消融中「LRT 全部显著但基因聚类自助 CI 全跨 0」同源（见 `results/ablation_expression_report_0923.md`）。**但去重口径的 p 不能反过来用于否定模型**：n=7 时双侧精确置换检验的 p 理论下限为 2/7! = 3.97e-04（仅 |ρ|=1 时取到），故该口径下几乎不可能得到显著性——它的作用是证明 n=198 口径的 p 不可信，而非证明模型无效。形态二 GLMM 的可信证据是**跨 16 个基因组折的 LOGO-CV**（以基因为分析单元，无伪重复），见表中 `rho_logo_cv_median` 与 `rho_logo_class_a_median` 两列。
2. **两个单模型在本数据上近乎冗余**：DeepSpCas9 与 CRISPRon 的测试集打分 Spearman ρ=0.9984；在 AUC 所用的两端掩码子集（101 行）内更高达 ρ=0.9999。所以"两个独立基线"实质上接近**一个**基线，这也解释了二者 AUC 仅差 0.0004、Class A 中位数完全相同。
3. **LOGO 中位数的分母不一致**：三个模型的有效折分别为 DeepSpCas9 单用 = 10/16；CRISPRon 单用 = 9/16；形态二 GLMM（本工作 · 生产模型） = 9/16。差异折为 `EVM.MODEL.LG03.2345`——该折内部分模型的打分无方差（ρ 无定义）而另一部分有方差。故三者的 LOGO 中位数**不是在同一组折上的比较**，横向差异应视为量级参考而非严格配对检验。
4. **AUC 定义**：沿用 `scripts/13:85-91`——取测试集 indel_pct 的 20/80 分位、掩出两端各 20%、以 q_high 为阈值二值化，三模型共用同一标签与同一掩码。在上述仅 7 条 distinct guide 的条件下该指标接近退化；旧表 `model_comparison_full_0916.csv` 三个模型 AUC 全为 0.0735 很可能同源于此退化，但该表为 487 行旧口径，本次未复核，**不作为可引用数字**。
5. **逐折 ρ 被 distinct guide 数量化，符号几乎是唯一信息**：16 个基因组折中每折的 distinct guide 数仅 1–4 条（中位 2）。折内 guide 这么少时 ρ 的可能取值是离散的几个数，实测 **9/9 折两个单模型的 ρ 完全相同**，而 GLMM 与 DeepSpCas9 在 **5/9 折上符号相反、绝对值相同**（含 `LG03.451` 的 ±0.852——正是方案2 消融中记录的那个翻转折）。故逐折 ρ 高度不稳，LOGO 中位数应连同有效折数与 Class A/B 分层一起引用，不宜单看某个数字。
