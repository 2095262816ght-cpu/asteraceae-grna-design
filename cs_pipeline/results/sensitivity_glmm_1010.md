| 维度 | 取值 | 说明 |
|---|---|---|
| 先验来源 | `full` = 全量 879 行估计（**现状**，scripts/15:56） | 测试折标签经 `u_prior` 进入训练（泄漏） |

| | 0.01 = 放开 | s<1 数学上合法（过离散更大） |

### 2.2 先验泄漏的影响（E0 → E1）

逐折对照（全量先验 → 折内重算）：

| 折 | 行数 | ρ(全量先验) | ρ(折内先验) | Δ |
|---|---:|---:|---:|---:|
| LG01.6995/6999 | 35 | −0.3878 | −0.0180 | **+0.3698** |
| LG07.3296 | 153 | +0.2071 | −0.2071 | **−0.4142（符号翻转）** |
| LG03.451 | 35 | +0.8522 | +0.8235 | −0.0287 |
| LG05.2725 | 306 | +0.3716 | +0.3635 | −0.0081 |
| LG07.3933 | 18 | +0.4972 | +0.4837 | −0.0135 |
| 其余 4 折 | — | 同值或无效 | 同值或无效 | 0 |

**读法**：
- **LOGO 中位（+0.3716→+0.3635）与 Class A 中位（+0.4636 不变）对泄漏不敏感**——核心结论稳健；
- **单一测试集 ρ 对泄漏敏感（+0.3424 → −0.0642）**：198 行仅 7 条 distinct guide，秩相关被少数 guide 的名次交换支配；泄漏方向为乐观，去掉后该数字失去显著性。
- 结论：**对外引用以 LOGO-CV 与 Class A 为准；留出测试集 ρ 只作方向参考，不作 headline**。

### 2.3 过离散度 s 的影响（E0 → E2）

- 放开下界后 s 收敛 **0.9275**（现状 clamp 下原始值 0.627、生效 1.0）——拟合想要的 s≈0.9，恰在旧边界附近；
- β 变化很小（最大 |Δβ| = 0.064：`deepspcas9_score` −0.206→−0.141），LOGO 中位 −0.02、测试集 ρ 与 Class A 不变；
- **读法**：s≈0.9–1.0，生效 1.0 顶在 clamp 下界 = 该参数化允许的过离散**最大值**（拟合还想要更小的 s）；**指标对 s_floor 不敏感**（β 变动 ≤0.06、指标变动 ≤0.02）——这只说明结论不依赖方差结构参数的精确取值，**不能推出"近似二项"**（s=1 时过离散因子 (n+1)/2，本数据 n≈50–3000，为二项方差的数十至千余倍；检验二项性应对比 s=1 与 s→∞，本实验未做）。模型卡 §5 的「s≈20.08」为误写初值（$e^{3}$），已更正；"过离散吸收"叙事按"过离散顶在允许的最大值、但指标不敏感"表述。（2026-10-11 更正：原文"近似退化为二项"方向有误。）

### 2.4 复现性校验（E0 vs 0921 冻结产物）

- 测试集 ρ = +0.3424、Class A 中位 = +0.4636、有效折 9/16——**与冻结指标逐位一致**；
- 逐折 ρ：7/9 折与 `folds_hier_bb_nob879_0921.csv` 逐位一致；`LG05.2725`（0.3635→0.3716）、`LG07.3933`（0.4837→0.4972）两折出现末位秩翻动；
- 全量重拟合 β 与落盘 joblib 第三位小数起有微差（如 β₀ −0.5096 → −0.5053）；
- **归因**：float32 LBFGS 跨 torch 环境的数值漂移 × 每折仅 1–4 条 distinct guide 的秩量化噪声（`LG07.3296` 折 ρ 在 ±0.2071 间翻符号即例证）——印证"逐折 ρ 基本是符号信息，不宜单看某个数字"。
