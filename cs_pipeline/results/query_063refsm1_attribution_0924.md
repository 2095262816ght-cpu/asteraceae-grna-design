三点值得注意：

1. **任何窗口下 guide A 的独占归属都是 0.0000。** 所以这不是"阈值选得不对"的问题。
2. **窗口取 ±6 时，guide B 覆盖 100% 的非 WT 读段**（0.9090），未归属归零。主信号
   （#1/#2/#3 合计 79.41%）全部落在 L103–105 / R62–64，即 B 的切点 L99 / R58 附近 4–6bp。
3. 窗口放宽到 ±8 以上时出现的"双切"（4.13%–5.24%）来自 #6/#7——它们在 L11 / L8 有变异
   （距 A 切点 8bp / 11bp），**但同时也在 L103 有变异（B 的位点）**。所以即便算作 A 有活动，
   也是与 B 同时出现的读段，不存在"纯 A"的证据。

## 六、请回答的三个问题

**Q1（核心）** `判定依据` 写的「计B经reads/Sheet2核实确认guide身份」，核实依据是哪一类证据？

- (a) **设计表 / Sheet2 的记录**——即"这个扩增子设计上递送的是 A"；
- (b) **reads 的切点分布**——即"读段里的切割发生在 A 的位点"。

若是 (a)，则 `TKS_1313` 的 `indel_pct = 0.9090` 实测上属于 **B 的活性**，而表里把它记在 A 的
序列名下 —— 这是一次序列↔效率的错配（与当初剔除 90 行 B 级"张冠李戴"同类），需要决定是
**改归 B 的序列**还是**整行剔除**。
若是 (b)，请指出我第四节归属方法的错误处，我据此修正。

**Q2** `guide候选` 表里 B 的**热点得分 220356** 是什么口径？（A 该行此项为空。）

- 若是**跨批次累计的读段支持数**，那 220356 远超本块的 2957 读段，说明 B 位点在大量样本中
  都被观察到切割——这会支持"B 才是实际起作用的 guide"；
- 若是**设计期打分**，则与本问题无关，请忽略此问。

**Q3** 同 ref 的 `057-refsm1`（`TKS_1307`，`indel_pct=0.0789`）与 `058-refsm1`
（`TKS_1308`，`indel_pct=0.1041`）两块中，**100% 的非 WT 读段落在 A、B 两切点 ±5bp 之外**。

第一个脚本会把本文第二、三、四节的每一行数字原样打印出来，并对「非 WT 占比 == 主表
`indel_pct`」做**硬断言**（不符即报错退出）。**请用它复核，不要采信本文的转述。**

其方法要点如下，其中第 1、2 条是我实际踩过的两个坑：

1. 定位块：在 TSV 中找整行等于 `063-refsm1` 的行，向下读到下一个 `^\d+-ref` 为止。
   ⚠️ **同一 ref 在单批次内有多达 29 个块**（USR-6883 共 94 块），必须按主表 `备注` 列的
   「块NNN-refXXX」精确定位，**不能按 ref 名取第一块**。
2. 参考读段：⚠️ **必须取该块 `Left/Right variation type` 均为 `WT` 的那一行**，不能取第一行。
   本块第一行（#1）本身带 1bp 插入且正落在 guide B 的原间隔序列内，用它会得出"B 不存在"的
   错误结论——我第一版就踩了这个坑，修正后 B 从"不存在"变为占 84.65%。
3. 定位 guide：在该行读段中同时检索 `seq20` 与其反向互补，命中起点 +17（+链）/ +3（−链）为切点。
4. 归属：对每个变异行，取其 `Left/Right reads seq` 中全部小写字母下标，若某下标到某 guide
   同侧切点的距离 ≤ 窗口，则记该 guide 命中；命中两个记"双切"，都不命中记"未归属"。

## 八、我方立场

我们**不主张**现在就修改主表或重训模型。理由是第五节：影响 Δ≈0.004，远小于该指标本身
的不确定度（测试集仅 4 个基因组 / 7 条 distinct guide）。

目前 `063-refsm1` 这一块回答不了。若 Q1 的答案是 (a)，最低成本的处置是在
`model_card_hier_bb_nob879_0921.md` 的局限性一节加一条如实说明，而非改数据。
