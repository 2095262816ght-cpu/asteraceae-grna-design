# ==============================================================================
# 一键安装（评委用）：主管线 + Web 后端 + DeepSpCas9 打分，同一 Python 环境
# ==============================================================================
#   pip install -r requirements.txt
#
# 装完即可运行（Python 3.10，实测 3.10.21）：
#   python scripts/emit_results.py                            # 生成 results/results.csv
#   python scripts/predict.py                                 # 模型推理（含 DeepSpCas9）
#   python scripts/15_train_hierarchical_bb_nob879.py         # 生产模型训练
#   python -m uvicorn backend.app.main:app --port 8000        # Web 后端
#   pytest tests/                                             # 无头测试套件
#
# 【为什么 CRISPRon 不在本文件】
#   genet==0.17.2 元数据锁死 tensorflow<2.10（本文件装 2.9.3），
#   而 CRISPRon 需要 tensorflow==2.14.0 —— 两个 TF 版本无法共存于同一
#   pip 环境，这是上游包的硬约束。因此 CRISPRon 真实打分独立为第二个
#   环境，见 requirements-crispron.txt 与 README「四、CRISPRon 真实打分」。
#   未装第二环境时，crispron 特征自动降级为经验近似式并逐条标注
#   `approximated`（界面会明确提示偏差），其余全部功能不受影响。
# ==============================================================================
