## 1. 系统架构与双轨矩阵

本系统严格遵循 **[ADR 0004: 生产级全栈架构升级](file:///d:/lifesciencechallenge/cs_pipeline/docs/adr/0004-fullstack-postgres-fastapi-react.md)** 与 **[SPEC-0001](file:///d:/lifesciencechallenge/.scratch/fullstack-postgres-react/spec.md)** 规范，采用现代生物信息平台的主流工程实践，构建了清晰的**双轨（Dual-Track）体系**：

```mermaid
flowchart TD
    subgraph Track1 [主推荐：生产级现代化全栈平台 (React 19 + FastAPI)]
        UI[React 19 + Tailwind CSS + ECharts] -->|REST / JSON| API[FastAPI 异步应用]
        API --> DB[(关系型数据库: PostgreSQL 16 / SQLite)]
        API --> Engine[核心生物物理与形态二分层推断引擎]
    end

    subgraph Track2 [对照轨：经典算法复现基准 (Ground Truth)]
        ST[Streamlit 单体应用 :8501] --> FileDB[Parquet / CSV 文件只读索引]
        ST --> Native[原生 DeepSpCas9 / CRISPRon 推理]
    end
```

| 系统维度 | 生产级全栈主轨 (本手册重点) | 经典基准对照轨 (Ground Truth) |
| :--- | :--- | :--- |
| **前端架构** | **React 19 + TypeScript + Vite + Tailwind CSS** | Streamlit 1.32+ Python 单体脚本 |
| **后端架构** | **FastAPI (ASGI) + Pydantic v2 + 异步并发** | 无独立后端（Streamlit 内部循环驱动） |
| **数据持久化** | **PostgreSQL 16 / SQLite 3 + SQLAlchemy 2.0 ORM** | 磁盘 Parquet / CSV 文件只读检索 |
| **可视化交互** | **Apache ECharts 基因组正负链双轨散点联动** | Altair / Plotly 静态切片图表 |
| **计算模式** | **非阻塞异步任务队列 + 1.5s 智能轮询进度条** | 阻塞式同步计算（等待期间页面冻结） |
| **适用场景** | 高并发实验设计、批量文件排队处理、历史追溯 | 算法单点复现、原始数据分布对账 |

## 2. 极速环境启动指南（1 分钟上手）

### 2.1 方式 A：Windows 双击一键启动（强烈推荐）

1. 在 Windows 资源管理器中打开项目根目录：`D:\lifesciencechallenge\`；
2. 直接双击运行：[`一键启动全栈系统.bat`](file:///d:/lifesciencechallenge/%E4%B8%80%E9%94%AE%E5%90%AF%E5%8A%A8%E5%85%A8%E6%A0%88%E7%B3%BB%E7%BB%9F.bat)；
3. **系统将自动执行以下全套流水线**：
   - 自动检测并优先采用 `D:\Miniconda\envs\grna-demo\python.exe` 科学计算环境；
   - **秒级缓存智能探测**：检测本地已有 `lifescience.db` 时秒级跳过重复数据灌库，大幅缩短冷启动时间；
   - 自动启动 FastAPI 异步后端服务（端口 8000）；
   - 启动 Vite 前端开发服务器并在**服务完全就绪的同一瞬间自动秒开默认浏览器**（访问 `http://localhost:5173`，告别转圈白屏）。

### 2.2 方式 B：PowerShell 终端启动

打开 PowerShell，切换至项目目录并执行：

```powershell
Set-Location D:\lifesciencechallenge
.\run_fullstack.ps1
```

*可选启动参数*：
- `.\run_fullstack.ps1 -SeedOnly`：仅执行数据库建表与数据灌库后安全退出，不拉起 Web 服务；
- `.\run_fullstack.ps1 -NoBrowser`：启动前后端服务，但不自动调用浏览器；
- `.\run_fullstack.ps1 -ForceSeed`：强制重新扫描原始 CSV 文件全量刷写灌入本地数据库。

### 2.3 方式 C：Docker Compose 容器化编排

在支持 Docker 的生产环境或 Linux 服务器中，执行：

```bash
docker-compose up --build -d
```
一键拉起 `db`（PostgreSQL 16 数据库容器）、`backend`（FastAPI Uvicorn 容器）与 `frontend`（Nginx + React 静态编译容器）。

### 3.2 模块一：候选 gRNA 靶位点检索与多维过滤面板

位于工作台第一大卡片，各控件与界面文字**100% 严格一致**：

```text

 │ 选择靶基因 (即输即搜 · 莴苣全基因组 + 49 NLR)             当前: LsaT2T01G023690 │

 ├────────────────────────────────────────────────────────────────────────┤
 │ 功能元件过滤 (Functional Region)                                       │
 │ 按植物基因组功能区段筛选 gRNA 候选位点（支持多选、单选或全不选）        │
 │  ☑️ [ 外显子 (Exon) ] 基因敲除 (Knockout)                               │
 │  ☑️ [ 启动子 (Promoter) ] 调控干涉 (CRISPRi/a)                         │

 │ 染色体: Chr01  区间: 83,870,025 - 83,876,080 (+链)  类型: NLR-LRR     │
 │ 候选靶点: 42 / 42 总条数                                                │
 └────────────────────────────────────────────────────────────────────────┘
```

#### 逐项操作说明：

1. **选择靶基因 (即输即搜 Combobox)**：
   - **控件特征**：带放大镜图标的输入框，支持直接在框内打字；
   - **模糊过滤**：输入基因编号（如 `019420`、`023690` 或 `000110`）、染色体（如 `Chr06`）或结构域（如 `CC` / `TIR`），下拉菜单即时过滤出匹配项；
   - **快捷键**：输入后直接按键盘 **`Enter`（回车键）** 自动选中首个匹配项并收起下拉；
   - **清空与展开**：右侧配有 `X` 清空按钮与 `▾` 折叠箭头。

2. **排序依据 (Sort By)**：
   - 系统提供 4 项排序维度下拉切换：
     1. **`效率分 (v2.1 推荐排序)`**【默认首选】：按形态二分层模型推断的内在生物学活性降序排布；
     2. **`基因物理起始坐标`**：按在染色体上的物理起始碱基位置排布；
     3. **`潜在脱靶位点数 (升序优先)`**：按 3 错配以内的全基因组脱靶数排序，保守性最高；
     4. **`GC 含量 (%)`**：按碱基 GC 比例排布。
   - **排序方向按钮**：点击 `⇅ 降序` / `⇅ 升序` 按钮可一键切换升降序。

3. **功能元件过滤 (Functional Region)**：
   - 包含两个独立的带色彩胶囊复选框：
     - **☑️ `外显子 (Exon)`**：蓝色高亮胶囊，专用于破坏编码框的基因完全敲除（Knockout）；
     - **☑️ `启动子 (Promoter)`**：紫色高亮胶囊，专用于转录起始区调控修饰或 CRISPRi/a；
   - **多选自由度**：
     - **默认状态**：两者均被勾选（全选展示，无遗漏）；
     - **支持单选**：可仅勾选外显子或仅勾选启动子；
     - **支持全不选**：支持将两者全部取消勾选（全不选时，下方表格将友好呈现空状态引导，绝不强制卡死）；
     - **快捷按钮**：右侧提供 **`全选`** 与 **`清空`** 快捷按钮。

4. **最低效率分过滤**：
   - **滑块量程**：`0 ~ 90 分`，步长为 5 分；
   - **默认值**：**`0 分`**（默认不拦截低分靶点，展示全部候选）；
   - **调节效果**：拖动滑块（如调至 60 分），表格和图表将即时过滤并剔除低于该分值的低效靶位点。

5. **排除着丝粒不稳定区靶点 (Centromere Filter)**：
   - **控件全称**：`排除着丝粒不稳定区靶点 (Centromere Filter)`；
   - **默认状态**：**`未勾选` (False)**；
   - **勾选效果**：打钩开启后，系统自动剔除落入植物着丝粒异染色质化高危区间的 gRNA，保障切割可及性。

6. **基因信息摘要条**：
   - 选定基因后，卡片底部深灰条即时呈现该基因的核心元数据：
     - **染色体**：例如 `Chr01`；
     - **物理区间**：例如 `83,870,025 - 83,876,080 (+链)`；
     - **结构域类型**：例如 `NLR-LRR` 或 `NLR-TIR`；
     - **候选靶点**：实时显示 `过滤后剩余条数 / 该基因全长总候选条数`。

### 3.3 模块二：基因组双链物理拓扑交互分布图（ECharts）

为解决传统设计平台“只看数据表、缺乏空间立体感”的问题，本系统集成了 **Apache ECharts 基因组正负链物理拓扑图谱**：

```text
  [Sense Strand 5'->3']    ·    ●(高活性)    ·       ●           
  ═══════════════════════════════════════════════════════════════ (基因物理骨架)
  [Antisense Strand 3'<-5']     ·         ●       ·      ●(高活性)  
```

- **X 轴绝对物理坐标**：完全对应基因在染色体上的真实碱基物理跨度（bp）；
- **正负链双轨分离**：
  - 上方轨道展示 **正链 (Sense Strand, +)** 靶点；
  - 下方轨道展示 **负链 (Antisense Strand, -)** 靶点；
- **效率分热力着色**：
  - 🟢 **翡翠绿 (≥70 分)**：高活性卓越位点；
  - 🟡 **琥珀黄 (40~70 分)**：中等可用位点；
  - ⚪ **冷灰色 (<40 分)**：低活性风险位点；
- **双向交互联动机制**：
  - **在图上点击任意散点** ──> 下方推荐表格自动**滚动并高亮选中**该行候选；
  - **在表格中点击任意行** ──> 拓扑图上对应散点立即**聚焦点亮**并弹出分子浮窗（Tooltip）。

### 3.4 模块三：候选 gRNA 靶位点推荐清单与浮动批量导出

位于页面中下部的数据表格：
1. **表头字段规范**：
   - `[ ]`：每行独立复选框（表头可全选当前页）；
   - `#`：全局排序序号；
   - `靶点 ID`：唯一编码（如 `Lsat_675191`）；
   - `方向`：正链显示浅蓝 `+`，负链显示粉红 `-`；
   - `基因组物理坐标`：如 `83,868,028 - 83,868,050`；
   - `区域`：蓝色徽标 `外显子 (exon)` 或 紫色徽标 `启动子 (promoter)`；

   - `PAM`：识别基序（如 `TGG`）；
   - `GC %`：碱基含量百分比；
   - `脱靶数 (≤3)`：错配 ≤3 的全基因组脱靶数，0 记为绿色，>0 记为橙色警示；
   - `着丝粒`：若位于着丝粒区显示红色 `着丝粒区` 警示，否则显示 `-`；

   - 显示：`X 个靶点已勾选`；
   - 支持在输入框中自定义：`批次方案备注名称（如：NLR_抗病核心验证批次）`；
   - 点击 **`导出 CSV`** 或 **`导出 Excel`**，系统自动建立导出批次并下载带 `UTF-8 with BOM` 的数据表（Excel 打开 100% 无乱码）。

### 3.5 模块四：30nt 靶位点序列实时打分与分子解构

**应用场景**：科研人员手头有一段 30bp 序列，想快速进行分子合规性检测与模型推断。

#### 1. 30nt 输入规范与强类型拦截
输入序列必须精确为 **30 个碱基（A/T/C/G，不区分大小写，自动过滤空格）**：

$$\underbrace{\text{T T T G}}_{4\text{nt 5'侧翼}} \;+\; \underbrace{\text{T G G A T T C C G G T A G A A T C T G A}}_{20\text{nt Guide 识别区}} \;+\; \underbrace{\text{T G G}}_{3\text{nt PAM}} \;+\; \underbrace{\text{A A T}}_{3\text{nt 3'侧翼}}$$

- **实时字数统计**：右侧展示 `X / 30 nt`；
- **合规性即时拦截**：若长度非 30 碱基、含非法字母、或第 25-27 位非 `NGG`（第 26、27 位非 `GG`），下方弹出红色警示并自动禁用提交按钮。

#### 2. 快捷示例填入
卡片右上角提供两个快捷填入按钮：
- **`填入示例 1`**：填入 `TTTGTGGATTCCGGTAGAATCTGATGGAAT`（`Lsat_675191 代表靶位点`）；
- **`填入示例 2`**：填入 `TGACAGCGTCTCGTTTCACGCTCAAGGTGG`（`外显子高活性靶点`）。

#### 3. 提交打分与结果展示
输入合法序列后，点击 **`开始实时打分`** 按钮（推理耗时 <100ms）：
- 输出 **综合预测效率分 (0~100)**；
- 输出 **GC 含量 (%)** 与 **退火解链温度 Tm (°C)**；
- 结果自动持久化入库，并提供「历史任务编号 (Job ID)」。

## 5. 常见问题排查与专家建议 (FAQ)

### Q1：为什么双击 `一键启动全栈系统.bat` 会非常快，它到底有没有做数据灌库？
- **答**：系统采用了**智能秒级缓存加速**机制。只要检测到本地数据库 `lifescience.db` 已经完整存在（45,981 全基因组 + 49 个 NLR 基因及其候选 gRNA 数据），脚本会自动秒级跳过耗时的 Python 重复冷启动，实现 1 秒拉起；如需强制重新刷库，只需在终端带参数运行 `.\run_fullstack.ps1 -ForceSeed` 即可。

### Q2：功能元件过滤（外显子与启动子）如果全部取消勾选会怎样？
- **答**：系统**支持完全自由地单选、多选或全不选**。当外显子与启动子均被取消勾选时，下方候选表格会呈现明确的空状态提示，并提供一个绿色的 **「一键恢复全选」** 按钮，操作极其自由，绝不卡死。

### Q3：为什么预测效率分不等于实验中实测的 Indel 突变率？
- **答**：生物学突变率强烈依赖于外植体分化生理状态、农杆菌侵染效价及组织培养温度，跨批次波动极大。模型输出的效率分属于**剥离批次环境扰动的纯内在活性相对排序量度**。在同一靶基因内，优先挑选 **效率分排名 Top 3~5 且脱靶评分最低** 的序列即可获得最高的实验成功率。

### Q4：为什么有些基因显示「⚠️ 表达证据缺失」横幅？
- **答**：组织表达图谱来自莴苣 v1.1c (LSA) 转录组数据，需要先经 **LsT2T↔LSA crosswalk** 把基因映射到 LSA 注释才能取到 TPM。映射分四级置信度：tier1 精确共线映射、tier2 明确主映射、tier3 救回未挂载 scaffold、tier4 **不可映射**（序列缺失/高度分歧/注释缺口）。tier4 基因系统会**如实标注表达证据缺失并说明原因，绝不编造 TPM 假值**——此时请以序列与效率预计算分做候选排序，表达维度仅对可映射基因生效。
