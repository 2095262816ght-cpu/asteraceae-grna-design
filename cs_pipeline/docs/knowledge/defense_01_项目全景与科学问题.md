## 1. 一句话定位（必须背下来）

> 面向菊科菊苣族（橡胶草 / 莴苣）的 CRISPR/Cas9 gRNA **设计与效率预测工具**：以 DeepSpCas9 + CRISPRon 双模型打分 + 8 维生物物理特征，经**分层选择性 Beta-Binomial GLMM（形态二）**集成排序（训练于自有 Hi-TOM 实测 `noB879` 纯 A 级金标准），扫描莴苣 T2T 基因组产生候选，结合多组织转录表达看板与 Cas-OFFinder 脱靶过滤，经 React + FastAPI 全栈系统交付「按基因检索 / 按序列打分」两种用法。

一句话讲清三个要素：**对象**（菊科植物 gRNA 设计）、**方法**（双预训练模型 + 分层 GLMM 集成〔选择性 EB 先验，MAP 拟合〕+ 多组学决策）、**交付**（全栈 Web 工具 + 金标准数据集 + 科学结论）。

## 2. 为什么做（科学问题）

**痛点**：CRISPR 育种第一步是选高效 gRNA，但现有效率预测工具（DeepSpCas9、CRISPRon 等）全部用人/鼠数据训练；植物——尤其菊科——没有专用工具，且"人源模型迁移到植物可不可靠"此前**没有定量答案**。

**本项目回答的科学问题**：人源数据训练的 gRNA 效率模型，迁移到植物体系是否可行？

**定量答案（三体系对照）**：

| 体系 | DeepSpCas9 ρ | CRISPRon ρ | 判读 |
|---|---:|---:|---|
| 人 HEK293T（in-sample 基准上限） | 0.774 | 0.876 | 文献 out-of-sample ≈ 0.5 |
| 本氏烟（Gong 2026，52 条） | 0.833 / 0.492 | 0.854 / 0.506 | 迁移良好 / 中等 |
| 番茄原生质体（Cucuy 2026，420 条） | **0.031** | **0.032** | **完全失效** |
| 橡胶草（自有 Hi-TOM） | 双模型分作为特征承载主要信号（移除后 LOGO ρ 0.404→0.157） | | **部分有效** |

**结论表述**：迁移可行性是**数据集特异**的——同两个人源模型在三个植物体系给出成功/部分/失效三种结局；两轮公开数据混合训练（人源 23,902 条、番茄 420 条，权重 50:1~5000:1）均"无害但无增量"；**自有小规模实测数据不可替代**，结合分层 GLMM（选择性 EB 先验）校正可显著提升判别能力。（来源：`results/transferability_0917.md`、`results/model_comparison_nob879_report_0924.md`）

| 4 | **多组学时空决策** | 莴苣 5 组织（根茎叶花种子）表达 + 16 批生物学重复（方案 1/3/5）；橡胶草 S1–S9 发育时相（方案 6）推荐产胶转化窗口 **S4** | `docs/reports/multiomics_five_schemes_implementation_report_0924.md` |
| 5 | **工具（排序推荐定位）** | 莴苣 T2T 基因区扫描 1,387 万候选 → Cas-OFFinder 脱靶过滤（错配≤3）→ Web 系统（React + FastAPI），按基因输出排序推荐表或按 30nt 序列实时打分 | `docs/reports/FULLSTACK_DELIVERY_ACCEPTANCE.md` |

工具的定位要如实说：**排序推荐工具**——同一基因内取 top 3–5 送实验终筛，输出是相对效率分（0–100），**不是绝对 indel% 承诺**。

## 6. 术语速查（中英对照，答辩卡壳救命表）

| 术语 | 英文/缩写 | 一句话解释 |
|---|---|---|
| 向导 RNA | gRNA / sgRNA | 20nt 可编程识别序列，把 Cas9 带到靶点 |
| 靶位点 | Target Site / seq30 | 4nt 侧翼 + 20nt guide + 3nt PAM + 3nt 侧翼 = 30bp |
| 种子区 | Seed / seed_6nt | guide 第 15–20 位（PAM 近端），结合解旋最敏感 |
| 前间区基序 | PAM (NGG) | 靶点下游必需识别基序，无 PAM 不切割 |
| 编辑效率 | indel% | 被编辑 DNA 分子占比（非 WT 读段占比） |
| Hi-TOM | Hi-TOM | 靶向扩增子深度测序定点突变检测，产出效率标签 |
| 批次效应 | Batch effect | 不同实验批次的系统性偏差（本项目实例：同 guide 4 批次差 16 倍） |
| 留一基因交叉验证 | LOGO-CV | 每次留出一个基因组做测试，防同源泄漏 |
| 秩相关系数 | Spearman ρ | 衡量预测排序与实测排序一致性，两篇核心论文主指标 |
| 广义线性混合模型 | GLMM | 固定效应 + 随机效应的回归框架，本项目形态二 = 分层 GLMM + 选择性 EB 先验（MAP 拟合，无后验区间） |
| 经验贝叶斯收缩 | Empirical Bayes shrinkage | 小样本估计向全局先验适度收缩，本项目"选择性 EB"按锚点数分段 |
| 金标准 | Gold standard | 经审计裁决的高置信训练/评估基准数据集 |
| 跨版本注释映射 | Crosswalk (LSA↔T2T) | 两套基因组注释 ID/坐标体系间的对应关系 |
| 可及性（ATAC） | Chromatin accessibility | 染色质开放程度，表观折中排序变体的加分项 |
| 脱靶 | Off-target | gRNA 在基因组其他位置的错配切割风险 |
