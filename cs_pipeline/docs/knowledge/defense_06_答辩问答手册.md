# 答辩学习 06：答辩问答手册（Q&A + 防雷清单）

> **用途**：临场模拟。每题给"核心回答（30 秒版）+ 展开要点 + 出处"。评委视角来自赛事评分标准（`docs/notification/` 附件 7/9）与教师反馈历史。
> **总原则**：① 先给结论再给证据；② 数字必带口径；③ 阴性结果与局限主动说——本项目的诚信设计（不硬猜、如实标注）本身就是得分点。

## A. 科学问题与创新性

### Q1. 你们的创新点是什么？
**30 秒版**：三点——① **数据**：橡胶草首个成规模 per-guide 实测效率金标准（noB879，公开渠道穷尽检索确认）；② **方法**：针对植物小样本 + 重批次效应，提出分层选择性 Beta-Binomial GLMM，端到端建模测序深度与批次效应，推断纯序列活性；③ **结论**：首次定量回答"人源效率模型迁移植物是否可行"——三体系对照显示迁移是数据集特异的（本氏烟 0.85 / 橡胶草部分 / 番茄 0.03），公开数据混合无增量。
**展开**：加上多组学时空决策（组织优先指数、产胶窗口 S4）与全栈排序推荐工具形成完整闭环。

### Q2. 为什么不用现成工具，要自己做？
现有效率预测工具全部用人/鼠数据训练，无菊科/植物专用工具；直接迁移在我们自己的数据上 AUC≈0.52（与随机无异）——不是"不用"，是"不可用"。本工作用自有实测数据校正后判别力显著恢复（AUC 0.7857）。（`results/model_comparison_nob879_0921.csv`）

### Q3. 与 Chen2022 的 Stacking 方案有什么区别？
Chen2022 用岭回归把多模型打分堆叠；我们早期（v1.x）正是这条路（487 行岭回归 Stacking，LOGO ρ=0.414）。升级点：① 训练数据换成审计后的纯 A 级金标准；② 似然层用 Beta-Binomial 直接建模 read count（深度加权内生）；③ 先验层用选择性 EB 处理批次效应，推断期剔除批次截距——Class A 中位从 +0.2653 提到 +0.4636（稳健证据），留出测试集 ρ 从 −0.5057 转正（该数字对先验来源敏感，仅方向参考，见 Q25b）。

## B. 数据相关

### Q4. 数据是你们自己测的吗？量有多大？
是团队自有湿实验数据（橡胶草 Hi-TOM 靶向扩增子测序，未发表）。24 批次 1,368 行原始交付，经治理链（裁决剔 360、弱信号剔 36、B 级剔 90）落地 **noB879 = 879 行 / 16 基因组**金标准。注意表述：行数多但 distinct guide 只有约 29–35 条——**信息量看 guide 数不看行数**，这是模型上限的根因，我们如实报告。

### Q5. 怎么保证标签质量？（数据治理）
七类历史问题系统修复（PAM 错记、坐标偏移、链向整列反转、indel 口径低估、多候选竞争、弱信号身份、编号地雷），每条有独立证据链（reads 切割点反推 + 基因组 + 注释三方互证）；独立双重审计（b_audit_0919/0920）发现两个阻断问题并修正；老师裁决 360 gid 落地。全部修改留时间戳备份可回滚。（defense_02）

### Q6. 批次效应怎么处理的？为什么不直接归一化？
直接证据：同一条 guide 4 个批次均值差 16 倍。批内 z-score/rank 归一化被否决——批次×guide 混淆（有的批次只测 1 条 guide），归一化会毁数据（对照实验 z 后 ρ 转负）。最终解法是**建模**：选择性 EB 先验按锚点数（跨批次共享 guide）分三段收缩批次截距，推断期剔除——实测 USR-14333 批次偏移 +0.85 被正确识别。（defense_02 §4、defense_03 §3）

### Q7. 会不会数据泄漏？
按 gene_group 分组划分（GroupShuffleSplit + LOGO-CV 留一基因组），结构上杜绝同源位点跨折；random_state=42 全队统一；公开数据不进生产训练；跨文件 join 禁令 + `_DEPRECATED` 隔离。未使用任何隐藏评测集。**主动交代**：自查曾发现评估协议层的批次先验泄漏（先验用全量数据估计，测试折标签经 u_prior 入训），已量化（核心结论 LOGO/Class A 不变，单一测试集数字降级为方向参考）并登记披露——见 Q25b。（defense_02 §7）

### Q8. 为什么剔掉 90 行 B 级？是不是挑数据刷指标？
不是。B 级是"多候选竞争、guide 身份未经设计表确认"的样本——标签可能挂在错误的 20nt 上，属系统性错配。影响量化：剔除后 LOGO ρ 反而从 +0.310 微降到 +0.297——**为标签可信度剔除，不是为指标**。

## C. 模型相关

### Q9. 模型是什么？能用一页纸讲清吗？
分层选择性 Beta-Binomial GLMM 三层（defense_03 §3 全文）：似然层 k_i~BetaBinomial(n_i, p_i, s)，logit(p_i)=β₀+zᵀβ+u_b（深度加权）；先验层 u_b 按锚点数分段 EB 收缩（≥10 紧约束 / 1–9 收缩 / 0 归零）；推断期剔除 u_b 输出纯序列活性 → sigmoid 映射到 0–100 相对分。PyTorch LBFGS 实现，CPU 训练数分钟。
**追问预答**：严格说是**经验贝叶斯 MAP 拟合**（惩罚似然点估计，无后验区间），别称"全贝叶斯"；过离散层实测 s 生效 1.0（顶在允许的过离散最大值，拟合还想要更小），但 **s 属方差结构参数、指标对其不敏感**（见 Q25b）。

### Q10. ρ=0.34 是什么水平？为什么没到 0.5？
先说口径：LOGO-CV 中位 ρ=+0.3635、低混杂核心折 Class A 中位 **+0.4636**（上限估计）；留出测试集 +0.3424（AUC 0.7857）**仅作方向参考**（7 条 distinct guide、对先验来源敏感，无泄漏口径 −0.06，见 Q25b）。参照系：两个人源预训练模型在同数据上 AUC≈0.52 与随机无异、甚至负相关——我们把"不可用"变成了"显著可用"。未达 0.5 达标线如实报告，根因是 **guide 多样性瓶颈**（16 个基因组、约 30 条 distinct guide），不是行数——扩数据的正路是湿实验（方案已在规划）。

### Q11. p=7.89e-7 可信吗？（伪重复）
不可单独引用，我们主动并列：留出集 198 行只含 7 条 distinct guide，有效样本量是 7；去重口径 ρ=+0.3063（方向稳健）。同时说明：n=7 的置换检验 p 下限 3.97e-4，去重口径几乎不可能显著——它证明 n=198 的 p 偏乐观，不否定模型。主证据是 LOGO-CV（以基因为分析单元、无伪重复）。自查还发现该 ρ 对批次先验来源敏感（折内重算后 −0.06），进一步说明它只能作方向参考（`results/sensitivity_glmm_1010.md`）。

### Q12. DeepSpCas9 和 CRISPRon 是两个独立验证吗？
不是——两者打分 ρ=0.9984，近乎同一基线，我们明确写在对比报告告警里。它们的价值是**特征**（移除后 LOGO ρ 0.404→0.157），不是两个独立评估源。

### Q13. 为什么效率分系数（deepspcas9/crispron 的 β）是负的？
小样本共线性 artifact（v2.0 阶段已诊断），不作生理解读。模型的实际判别力以留出与 LOGO 评估为准；且移除这两维特征性能显著下降，说明信息在联合使用中。

### Q14. 10 维特征为什么选这些？能换吗？
2 维深度模型分（人源数据学到的通用 Cas9 规律）+ 8 维可解释生物物理量（GC、种子区 GC、Tm、poly-T 终止信号、PAM 首位 one-hot）。小样本下低维可解释特征 + 预训练分是过拟合风险最低的组合；特征列单点定义、训练推理同源。未来数据量上去可扩基因组/表观特征（方案 4 的 32 维蓝图），但需"基因内可变"才有效（见 Q17）。

### Q15. 预测输出是什么？能告诉我这条 gRNA 的 indel% 吗？
输出是**同一基因内候选择优的相对排序效率分（0–100）**，不是绝对 indel% 承诺。理由：① 标签跨批次系统偏移（16 倍差异）；② 批次截距被显式剔除，输出是纯序列活性潜变量；③ 排序工具定位 = 取 top 3–5 送实验终筛，降低试错成本。

## D. 多组学与脱靶

### Q16. "多组学"体现在哪？不就是个表达矩阵吗？
五层落地：① 五组织表达看板 + 表型预警（方案 1）；② 表达×效率消融（方案 2，阴性结论排除混杂解释）；③ 组织优先指数真实改变推荐（Leaf top50 与纯效率 top50 仅重叠 1 条，方案 3）；④ 功能性脱靶危害（面板内 10,120 位点加权，方案 5）；⑤ 橡胶草 S1–S9 产胶时相窗口（方案 6，推荐 S4）。另有 ATAC 可及性折中排序变体与 NLR 功能域注释轨道。

### Q17. 表达量为什么没进效率模型？
方案 2 消融给出硬证据：表达是**基因级常量**，LOGO 折内 Spearman 对常数平移不变（折内标准差 4e-16、Δρ 严格 0）；嵌套 GLMM 表达系数 100 次基因聚类自助 CI 全部跨 0——**无表达效应**。所以表达用于**决策层**（组织适宜性、脱靶危害、转化窗口）而非效率回归，这是数据性质决定的正确分工。

### Q18. 跨物种表达映射靠谱吗？
四套 ID 命名空间互不对应，我们做的是**不硬猜**的分层映射（锚点投票 → guide 级精配 → scaffold 救回 → 诚实 unmappable），tier 语义与阈值单点定义并有回归测试。全基因组 45,981 基因可映射 78.0%，22.0% 如实标"表达证据缺失"。完整版 liftover 曾预注册 4 判据实验验证，1 过 3 否证后果断搁置——降级有据，不是做不到。

### Q19. 脱靶怎么算的？和 CRISPOR 什么关系？
两层：① 全局过滤层 = Cas-OFFinder v2.4.1（≤3 错配，demo 范围 19,839 guide / 608 万命中位点）+ 着丝粒回避；② 详情评分层 = 自研 5-mer 种子筛 + Hamming 验证输出位点明细，CFD（Doench 2016）与 MIT/Hsu 2013 评分沿用 CRISPOR 公式口径、与官方 doctest 逐位一致。功能性脱靶危害再叠加非靶标组织表达加权（方案 5 公式）。

### Q20. S4 转化窗口的依据？
REF/SRPP/CPT 三家族在胶乳的表达峰值/爆发期均在 S4–S5（REF 首采样即峰 6,225 TPM），根部爆发期 S4–S7 佐证；样条导数取"主峰前上升段最大处"修正了端点失真。S4 之前无采样点，已如实标注不可观测。

## E. 系统与工程

### Q21. 工具怎么部署？评委能跑起来吗？
三条路：pip 一条命令装齐 → `一键启动全栈系统.bat`；或 docker compose；或离线镜像包（无网环境）。大数据外挂挂载，缺失时功能逐项降级提示。实测锚点可现场复现：示例序列 `ATCGGCTAAGCTAGGCTAGCATCGTGGATC` DeepSpCas9 打分 71.2494。

### Q22. CRISPRon 没装怎么办？
不影响其余任何功能——该维特征逐条降级为经验近似式并标注 `approximated`（琥珀徽标 + "实测可偏约 15%"），绝不冒充真实模型输出。来源裁决单点实现（`crispron_scorer.py`），有历史教训背书（曾有漏标事故，已收口）。

### Q23. 架构上有什么讲究？
洋葱三层（纯领域 / 后端 / 前端）+ 四个深度模块（SequenceSpec、InferenceClient、CandidateRankingEngine、ranking_semantics）各有 ADR 记录决策与理由；接口窄、实现深、可脱离 UI 单测；公式与文案单点定义防漂移；双轨（全栈 + Streamlit 黄金基准）数值比对 100% 吻合验收。（defense_05）

### Q24. 测试覆盖怎么样？
自动化测试全链路：核心模块单测（SequenceSpec/Engine/InferenceClient）、批处理、CRISPRon 裁决、ATAC、crosswalk"不硬猜"断言、双轨一致性测试；0929 时点后端 65/65、前端 25/25 通过。测试纪律：隔离测试库，禁对真实库跑套件（有过事故，已立规）。

## F. 诚实与局限（评委必问，主动出击）

### Q25. 项目最大的局限？
三条：① **数据规模**：约 30 条 distinct guide / 16 基因组，ρ 上限受限，0.5 达标线未达到；② **标签口径**：含本底 SNP、双 gRNA 归属个别错配（38 行，敏感性验证影响 ≈0）；③ **跨物种泛化**：模型训练于橡胶草，任意物种可打分但需声明局限。均有量化披露与敏感性验证。

### Q25b. 你们自己复查发现过什么问题？（主动亮出来加分）
两项自查发现，均已量化并登记（`results/sensitivity_glmm_1010.md` + CHANGELOG 2026-10-10）：① **交叉验证的批次先验泄漏**——先验曾用全量数据估计（含测试折标签），折内重算后 LOGO/Class A 不变（+0.3635/+0.4636 稳健）、单一测试集 ρ 由 +0.34 转为 −0.06，故对外一律以 LOGO/Class A 为准；② **模型卡过离散度数字误写**——"s≈20.08"实为拟合初值，实测 0.632、生效 1.0（clamp 下界 = 该参数化允许的过离散最大值；指标对 s 不敏感，Δ≤0.02），已更正。发现→量化→修正→披露，全程有脚本与产物可查。这正是本项目"不硬猜、缺啥写啥"纪律的自我适用。

### Q26. 有什么失败/放弃的东西？
两个如实报：① 公开数据混合训练两轮均无增量，按纪律终止建模；② 方案 4（多组学重训冲 0.5）与方案 5 完整版（liftover）经预注册判据否证后正式降级。阴性结果排除了替代解释，是科学结论的组成部分。

### Q27. 数据/代码可复现吗？
脚本链路端到端可复现（训练→扫描→脱靶→多组学→结果文件），random_state=42 统一，指标冻结记录（CHANGELOG_0927）与折级明细归档；不便随包的（原始测序、399MB 脱靶原始输出、第三方模型权重）均给出获取方式。匿名评审版不含任何个人信息。

### Q28. 下一步计划？
① 湿实验扩 guide 多样性（唯一正路，参考莴苣毛状根验证平台）；② 植物自有特征（染色质/表观，番茄实验提示有效特征与人源不同）；③ 基因内可变特征纳入（需满足稳健性判据）；④ 菌株/作物扩展与工具产品化。

## H. 上场表述规范

1. **每次报数字带口径**（数据集 + 评估方式 + 有效折/样本数）；
2. **先说结论再说证据**，证据按"冻结产物文件名"引用（显得有据可查）；
3. **主动交代局限**（Q25 材料），把"诚实标注体系"（不硬猜、缺啥写啥）作为工程方法论亮点讲；
4. 被问到不确定的数字：**宁可说"以 results/ 冻结记录为准，我不现场编"**，也不要猜；
5. 双轨演示走"按基因检索 → top 3–5 推荐 → 按序列打分（含降级标注演示）→ 导出（指标方法说明 sheet）"四步，每步对应一个评分点。
