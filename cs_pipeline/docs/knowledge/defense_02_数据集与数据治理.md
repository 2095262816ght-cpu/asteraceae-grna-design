## 1. 数据来源与标签定义

- **来源**：橡胶草（*Taraxacum kok-saghyz*，TKS）**Hi-TOM 靶向扩增子测序**，团队自有湿实验数据、未发表。原始交付 `data/raw/`（24 批次 / 1,368 行，不随包发布），清洗后快照随代码发布。
- **Hi-TOM 原理**（答辩一句话）：把每个靶位点 DNA 片段 PCR 扩增（约 300–400bp）后深度测序，统计带插入/缺失（indel）的读段占比，直接读出每个 gRNA 的编辑效率——**标签自动生成，无需人工标注**。
- **标签定义**：`indel_pct` = 该样本块非 WT 读段占比（1 − WT 比例），经 11 个已知值交叉验证反推确认（`docs/reports/project_progress_report.md` 9.25 段）。注意与 `hitom_reads_depth_0921.csv` 的 naive `non_wt/total` 不同源（879 行中仅 229 行相等，r=0.68）。
- **二倍体生物学**：约 60 行"100% 编辑率"经核实为**真实离散基因型**（1.0 / ~0.5 / ~0.1 ≈ 纯合 / 杂合 / 未编辑），不是错误。

## 2. 数据规模演进链（必须能画出来）

```
原始 xlsx 491 行 / 23 条 guide / 14 基因 / 7 批次（9.03 交付）
   │  9.18 NEWdata 并入（10 真新批次 + 5 遗留批次，去重 6 重复批次）
   ▼
合并表 1,368 行 / 24 批次（47 条 distinct seq20）
   │  9.19 老师裁决：剔 360 gid（USR-14333 整批 87"疑 T2 代测序"、USR-22807 整批 20 等）
   ▼
1,005 行（16 版口径）
   │  弱信号 36 行剔除（热点最高分<100，guide 身份不明）
   ▼
训练集 969 行（16.1 现行交付版）｜另有"保留-不可打分"3 行
   │  9.21 全队会签：剔 90 行 B 级（多候选竞争、未经设计表确认）
   ▼
noB879 = 879 行 / 16 基因组 —— 纯 A 级金标准（生产模型唯一训练基准）
```

- **16.1 版算术闭环**：1,368 = 保留 969（训练集）+ 保留-不可打分 3 + 剔除(裁决) 360 + 剔除(弱信号) 36；969 + 36 = 1005 与裁决口径闭环。
- ⚠️ **口径提醒**：部分文档写"879 行 / 35 条 distinct guide"，实测 35 条是 **train969** 的 distinct seq20 数，noB879 实测为 **29 条** distinct seq20。答辩引用建议说"约 30 条 distinct guide、16 个基因组"，或明确口径。

## 4. 批次效应：证据、否决方案与最终解法

**直接证据**：同一条 guide `GGCGTTAGATTGACAGAAGA` 在 4 个批次均值差 **16 倍**（0.045 ~ 0.929）——批次效应不是理论担心，是实测事实。

**为什么不做批内归一化**：批次×guide 严重混淆（5 个批次只测 1 条 guide），批内 z-score/rank 会毁掉 147/487 行（对照实验：raw 0.388 / z −0.077 / rank −0.129）。

**锚定校正（v2.0~2.1 过渡方案）**：取跨批次共享 guide（同一 seq20 出现在 ≥2 批次，序列效应抵消）→ 每批偏移 = 共享 guide 行「indel − guide 全局中位数」的中位数 → 标签减偏移。实例：USR-14333 被算出整体偏移 **+0.85**（虚高实锤）；train969 口径 LOGO 由 −0.248 拉到 **+0.310**。

**形态二的端到端解法（现行）**：不再"先减中位数再回归"，而是把批次效应放进模型：
- 似然层直接用测序深度 n_i（Beta-Binomial，深度加权内生）；
- 先验层按锚点数分段选择性 EB（详见 defense_03）；
- **推断期剔除批次截距 u_b**，只输出纯序列生物学活性。

## 5. A/B 分级与"为什么剔 90 行"

- **背景**：2022–23 年设计台账（合成订单/送测单）无法找回，改由 **reads 切割点反推 + 几何验证**自动定级（7 条规则，`docs/reports/scoring_rules_14-15_0920.md`）。
- **A 级** = guide 身份证据充分（热点 Top1 分数高、与次选差距大）；**B 级** = "多候选竞争"（Top1 热点分 100~500 或与次选差距 <4 倍），guide 身份只是临时转正，**guide-id ↔ 序列对应关系不可信**。
- **为什么剔**：B 级入模 = 标签挂在错误的 20nt 上 = **系统性错配**（不是噪声，是伪特征）。90 行 B 级集中在 LG05.1856（66 行）等 5 个基因座。
- **裁决链**：9.19 老师裁决（360 gid 剔除清单）→ 9.20 独立审计发现两阻断（B1 效率综合分被人为 tie-break 抖动摊开；B2 裁决未落地，28 行误保留/94 行误剔）→ 9.21 修正版 16.1 + 全队会签剔 B 级 → `noB879`。
- **影响量化（可主动说）**：去 B 级后锚定 LOGO +0.297 vs 含 B +0.310——"B 级影响小"，剔除主要是**为标签可信度**而非刷指标。

## 6. seq30 序列回溯

- **seq30 布局**：4nt 上游侧翼 + 20nt guide + 3nt PAM + 3nt 下游（沿 guide 5'→3' 方向）。
- 两条构建路径：① 坐标版（按 chrom/start/end/strand 从 TKS 基因组切片 + 反向互补）；② CDS 回溯版（早期坐标缺失，regex 搜索 23nt = seq20+PAM，要求正反链合计唯一命中）。
- 硬校验：长度 30、全 ACGT、`seq30[4:24]==seq20`、`seq30[24:27]==pam`（防取向反了）。
- 最终 1,361 行可打分 = 1,061 CDS + 300 基因组坐标回退（内含子/基因间区靶点），unmatched 清零。

## 7. 数据泄漏防控（评审重点）

| 风险 | 防控措施 |
|---|---|
| 同 guide 跨折泄漏（相邻 gRNA 序列高度相似） | **按 gene_group 分组**：外层 GroupShuffleSplit(test_size=0.2, random_state=42) 留出 + 内层 LOGO-CV（留一基因组，16 折）——结构上杜绝位点级泄漏 |
| 脏标签污染 | 剔 90 行 B 级 + 36 行弱信号 |
| 跨文件编号错配 | `_DEPRECATED` 改名、禁止按 guide-id join |
| 双 gRNA 归属错配 | 38 行读段级复核 + 敏感性验证（整体剔除 ρ 仅 −0.0010） |
| 公开数据污染生产模型 | 生产脚本只读 noB879；公开数据仅用于迁移对照实验 |
| 标签本底 SNP | 逐块披露（SNP-only 占非 WT 0.68%，个别块 13.4%），维持原口径 |
| 随机性 | `random_state=42` 全队统一（06/13/14/15/24/25 脚本）；LOGO-CV 确定性无随机 |
| 评估协议批次先验泄漏（2026-10-10 自查发现） | 批次先验曾用全量 879 行估计，测试折标签经 u_prior 进入训练——已量化（折内重算后 LOGO/Class A 不变，单一测试集 ρ 对先验来源敏感）并登记披露；对外引用一律以 LOGO/Class A 为准，折内重算协议待全队决定（见 defense_03 §4.4、`results/sensitivity_glmm_1010.md`） |

**声明**：未使用、亦不掌握任何未公开隐藏评测集。
