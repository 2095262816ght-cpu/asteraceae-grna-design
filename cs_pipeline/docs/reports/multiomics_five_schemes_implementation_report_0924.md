## 0. 十分钟速览

### 0.1 项目一句话背景

我们在做一个**植物 CRISPR 基因编辑的 gRNA 设计工具**：给定一个目标基因，从基因组上扫描出
成千上万条候选 guide RNA（gRNA），用模型给每条打分（预测它"切得动"的概率），再排除会
"切错地方"（脱靶）的候选，最后把最好的几条推荐给用户送实验验证。比赛评审看两件事：
**推荐排序准不准**（用留一基因交叉验证的 Spearman 相关系数 ρ 衡量），以及**工具有没有真科学含量**。

2026-09-22，团队收到一批**新的转录组表达数据**（莴苣 5 组织表达矩阵 + 橡胶草 9 个发育时期
× 5 组织表达矩阵）。计划文档据此提出六个"应用方案"，想把这些表达数据用起来。
本报告记录其中五个方案在 09-23 ~ 09-24 两天的实施全过程。

### 0.2 最终结果一览

| 方案 | 原计划意图 | 最终状态 | 一句话结论 |
|---|---|---|---|
| 1 表达看板 | Demo 里展示基因在 5 个组织的表达量 | ✅ 交付 | 看板 + 表型诊断上线；14 个无表达注释的基因如实标注而不编造 |
| 2 表达消融 | 证明"表达量影响编辑效率" | ✅ 交付，**结论为阴性** | 在 16/17 个靶基因上**未检出**表达量与编辑效率的关联；原评估设计被证伪后重设计 |

## 1. 名词表（写给非本领域读者）

| 术语 | 解释 |
|---|---|
| CRISPR/Cas9 | 基因编辑技术：Cas9 蛋白在一段 guide RNA（gRNA）带领下结合到基因组匹配位置并切断 DNA |
| gRNA / guide | 20nt 的引导序列 + 紧邻的 PAM（NGG 三碱基）；本工具的设计对象 |
|  on-target / 编辑效率 | guide 切中目标位点的能力；实验以 indel（插入缺失）读数占比衡量 |
| off-target / 脱靶 | guide 因序列相似而切错的其他基因组位置；错配数越少（mis0/1/2/3）越危险 |
| TPM | 转录组测序的表达量单位（每百万转录本中每千碱基的读数）；TPM<0.5 视为"转录静默" |
| τ（Tau） | 组织特异性指数：τ→1 表示基因只在一个组织表达，τ→0 表示到处都表达（管家基因） |
| LOGO-CV | 留一基因交叉验证：每次把一个**基因**的全部样本当作测试集、其余基因训练，轮换遍历；衡量模型对"没见过的新基因"的泛化能力 |
| Spearman ρ | 秩相关系数，−1~+1；本项目用逐折 ρ 的中位数作为排序准确性指标，达标线 0.50 |
| Beta-Binomial GLMM | 本项目生产模型（v2.1）：把每个样本的 indel 读数建模为 beta-二项分布，带批次随机截距的广义线性混合模型 |
| 伪重复（pseudoreplication） | 把非独立观测当独立观测用：如 879 条 guide 只来自 16 个基因，基因级协变量的有效样本量是 16 而不是 879 |
| LRT | 似然比检验：比较嵌套模型的对数似然差，近似服从 χ² 分布 |
| 聚类自助（cluster bootstrap） | 以**基因**为重采样单元做 bootstrap，得到尊重有效样本量的置信区间 |
| NLR | 植物抗病基因家族（NOD-like receptor），本 demo 的 49 个靶基因；基因组上成串联簇排列、旁系同源高度相似 |
| 莴苣 / 橡胶草 | 两个物种：莴苣（*Lactuca sativa*，demo 与脱靶评估对象）；橡胶草（*Taraxacum kok-saghyz*, TKS，产天然橡胶，Hi-TOM 实测训练集与方案6 对象） |
| 组装 / 注释 / GFF | 组装=拼出的基因组序列；注释=基因在序列上的坐标与结构；GFF=注释的文件格式 |
| v1.1c / T2T | 莴的两套基因组组装：v1.1c（表达矩阵所用）与 T2T（demo 候选坐标所用）。**两者坐标系互不兼容**，是本项目最大的数据陷阱 |
| crosswalk | 两套基因编号/坐标体系之间的映射表 |
| liftover | 把一套组装上的坐标转换到另一套组装上（通常靠全基因组比对） |
| PAF / asm5 | minimap2 比对器的输出格式 / 用于同物种组装间比对的参数预设 |
| 鸽笼原理种子筛 | ≤3 错配分布在 20nt 上 ⇒ 把 20nt 切 4 块（各 5nt）必有一块完全匹配；用完全匹配的块做索引候选，再逐条验证 |
| Smith-Waterman | 经典局部序列比对算法，用于同源基因判定 |
| Streamlit / AppTest | Python 的 Web demo 框架 / 其无头（不起服务器）自动化测试工具 |

## 3. 基础设施：LSA↔T2T crosswalk（`scripts/16`）

### 3.1 选型对比实验（10 基因样本，跨 Chr01–Chr05）

对比两条路线：

- **方法 A（基因座级）**：先用 guide 序列在本地 T2T 基因组重建每个基因的真实基因座，
  再用 40-mer 锚点投票出 T2T→v1.1c 的坐标偏移，把基因座中点映射过去，落进 v1.1c GFF 基因区间。
- **方法 B（guide 级）**：每条 guide 的 20-mer 直接在 v1.1c 上锚定（精配优先、≤2 错配容忍），
  逐条落到基因区间，基因级投票取众数。

结论：

1. 两法在可解析基因上**结论一致**；
2. 非串联簇基因方法 B 近乎完美（如 Chr03 基因 327/328 票单一 LSA）；
3. NLR 串联簇基因方法 B 投票发散（2–10 个 LSA）但**众数仍等于方法 A 的答案**；
4. 方法 A 失败的基因（锚点崩掉）方法 B 也基本打不中——**失败是可检测的，不会被硬凑成错误答案**；
5. 有基因被"留在未挂载 scaffold 上"（v1.1c 的 640 条 scaffold 之一），只有全 seqname 搜索才能救回。

**定案：分层混合**——方法 A 的 offset 给方法 B 提供窗口（速度来源），方法 B 做逐 guide 解析与投票，
scaffold 搜索作为第三层救回搬迁基因，第四层标记 unmappable。

### 3.2 分层设计与解析规则

```
tier1  本染色体 ±20kb 窗口内精配 / ≤2 错配     （窗口由方法A offset 预测）
tier2  本染色体无界精配（每基因封顶 25 条 guide）
tier3  v1.1c 未挂载 scaffold 无界精配（封顶 6 条 guide，需 ≥3/6 共识）
tier4  标记 unmappable，不猜
```

解析区间为**启动子感知**：`[start−2000, end]`（+ 链）/ `[start, end+2000]`（− 链），
与既有扫描脚本 `scripts/07` 的设计（TSS 上游 2000bp + 全部外显子）一致；
nearest 兜底仅限 2kb 内。串联簇记录**全部簇成员**（投票 ≥10%），不假装 1:1。

### 3.3 结果

- 49 基因 / 19,839 条 guide：**35 个（71.4%）映射成功**且 LSA 在表达矩阵中；
  tier 分布 {1: 11, 2: 21, 3: 3, 4: 14}。
- 3 次 scaffold 救回：`LsaT2T01G036880`→LSA26099（HiC_scaffold_1，3/6 共识）、
  `LsaT2T04G000980`→LSA112（HiC_scaffold_15，6/6）、`LsaT2T09G006480`→LSA32527（HiC_scaffold_5，6/6）。
- 7 个串联簇基因带成员列表，例：`LsaT2T01G023690`→LSA25643（vote 0.819，
  簇 `LSA25643:307; LSA25641:68`）。
- 14 个 unmappable 基因分两类可解释原因：**序列在 v1.1c 缺失/高度分歧**；
  **序列共线但 v1.1c 注释缺口**（最近基因模型 >2kb，如 `LsaT2T05G000020`）。
- 同时产出两个特征库：莴苣 40,267 基因 × 5 组织 parquet（log2 TPM、max/mean、τ、biorep CV）；
  TKS 36,239 基因 × 5 组织 CSV（固定 S9 胶乳口径）。

### 3.4 六个工程缺陷中的三个（crosswalk 相关）

每个都是"先观测到异常、再定位根因、再修、再验证"：

1. **隐式无界全扫（性能炸弹）**：窗口查找失败时函数内部会静默退化为整条 259Mb 染色体的
   全串扫描（≈3 秒/条）。一个窗口几乎全失败的基因（280 条 guide）实测独占 **14 分钟**。
   修复：窗口调用禁止内部全扫，无界代价只走带封顶的 tier2/tier3。修复后该基因 ~2 分钟→秒级。
2. **弱票硬凑（正确性炸弹）**：解析占比仅 0.7% 的基因曾靠着重复序列驱动的 19 票拿到
   "LSA25010" 这样看似可信的答案。修复：解析占比 <0.2 且 tier3 无共识 ⇒ **弱票作废、标记 unmappable**。
3. **基因座宽度退化（内存/性能炸弹）**：p10–p90 百分位区间在双峰命中分布下退化成
   **83–201Mb** 的"基因座"，5-mer 索引直接爆炸、进程卡死。修复：>300kb 时改用
   "覆盖 ≥60% 命中的最窄窗口"，仍过宽则弃用该基因座（与 §5.4 的方案5 共用同一守卫）。

## 4. 方案 2：表达量到底影不影响编辑效率？（阴性结果）

### 4.1 原设计为什么在结构上不可能成功

计划文档原设计：Group A（纯序列特征）vs Group B（+表达特征）跑 LOGO-CV，比较逐折 Spearman ρ，
Wilcoxon 检验 Δρ。问题在于：

- 表达特征是**基因级常量**（一个基因一条表达值）；
- LOGO 的一个测试折**恰好就是一个基因**的全部样本；
- 生产模型的推断路径剔除批次随机截距，折内预测 = 截距 + 序列特征线性项；
- 于是表达项对折内所有样本加的是**同一个常数**，而 Spearman 秩相关对常数平移**完全不变**。

实测佐证：表达项在折内的标准差最大 **4.4×10⁻¹⁶**（机器零）；Δρ 中位数**严格为 0**、
noB879 的 9 个有效折中 7 个 Δρ 恰为 0。**对这样的 Δρ 做 Wilcoxon，检验的是噪声。**

### 4.2 重设计：在正确的分析单元上检验

- **Block 1（主结果，基因级）**：以"Selective EB 批次偏移校正后的基因平均 indel"为因变量，
  对 5 个表达特征做 Spearman / 加权回归；并给出剔除 5 个"基因与批次完全共线"基因后的敏感性分析。
- **Block 2（嵌套 GLMM）**：在生产模型似然上逐个加入标准化表达协变量，报告 γ、LRT，
  以及**以基因为重采样单元的 100 次聚类自助 95% CI**。
- **Block 3（方法学负对照）**：保留原 A/B LOGO 对比，用于实证 §4.1 的结构性论断，
  并记录逐折预测标准差与表达项折内标准差。

### 4.3 结果（noB879，16 个基因组；train969 敏感性一致）

**Block 1：全部不显著，点估计偏负。**

| 表达特征 | n | Spearman ρ | p | 剔除共线后 ρ (n=11) | p |
|---|---:|---:|---:|---:|---:|
| log2(根) | 16 | −0.127 | 0.641 | +0.045 | 0.894 |
| log2(叶) | 16 | −0.344 | 0.192 | −0.054 | 0.873 |
| log2(胶乳) | 16 | −0.159 | 0.557 | −0.118 | 0.729 |
| 发育均值 | 16 | −0.268 | 0.316 | −0.100 | 0.770 |
| τ | 16 | −0.138 | 0.610 | −0.200 | 0.555 |

直观例证：表达最高的 `LG01.555`（发育均值 log2 = 10.72，峰值 6,225 TPM）平均 indel 仅 0.309、
**中位数 0.028**；表达最低的 `LG03.2345`（2.45）为 0.142。**高表达 ≠ 高效率。**

**Block 2：伪重复的教科书案例。** 5 个 γ 全为负，LRT 全部"显著"，但聚类自助 CI **全部跨 0**：

| 协变量 | γ | LRT χ²(1) | p | 基因聚类自助 95% CI |
|---|---:|---:|---:|---|
| log2(根) | −0.183 | 5.58 | 0.018 | [−0.866, +0.920] |
| log2(叶) | −0.362 | 18.80 | <0.0001 | [−1.112, +0.305] |
| log2(胶乳) | −0.246 | 8.31 | 0.004 | [−0.959, +0.886] |
| 发育均值 | −0.202 | 7.07 | 0.008 | [−0.964, +0.782] |
| τ | −0.413 | 36.05 | <0.0001 | [−0.998, +0.436] |

LRT 按 879 行计自由度，而表达协变量只在 16 个基因之间变化——**p 值系统性过度乐观**；
以基因为单元的 CI 才是诚实的推断。**结论以 CI 为准：无表达效应。**

**Block 3：负对照 + 一个意外发现。** A/B 中位 ρ：noB879 +0.3635 → +0.2204（Wilcoxon p=0.18）；
train969 +0.1985 → +0.0716（p=0.86）。下降并非表达"有害"，而是单一折的**符号翻转**：
`LG03.451` 的 ρ 从 **+0.8522 翻到 −0.8522**。诊断排除了优化器问题（max_iter 80/200/600 结果完全一致），
真因是加入协变量后**近共线的序列特征被重新配权**（A：Tm +0.987 / GC −0.818；B：GC −0.941 / Tm +0.897，
且第 3、4 位特征换人）。**推论：逐折 LOGO ρ 在特征集扰动下高度不稳定**——这一条直接改写了
方案4 的达标判据要求（见 §8）。

### 4.4 这个阴性结果的价值

### 5.2 方案 3：组织特异优先指数重排（`scripts/21`）

公式按计划文档：

```
PriorityScore(i, t) = 0.50·Percentile(效率分_i) − 0.25·Penalty(脱靶_i) + 0.25·S(E_t(g))
S(E) = 1/(1+e^−(E−2.0))，E = log2(TPM+1)
Penalty = min(1, (mis0·1.0 + mis1·0.5 + mis2·0.2 + mis3·0.05)/10)
```

- 百分位在**全部 19,839 条候选**内计算，使分数跨基因可比（方案3 的目标就是全基因重排）。
- unmappable 基因表达项记 0（无证据即无加分）并以 `expression_status` 标注，
  前端显示"表达证据缺失"而非"转录静默"——两者生物学含义完全不同。
- 实测：Leaf 优先指数 top50 与纯效率分 top50 **仅重叠 1 条**——重排真实改变推荐，不是装饰。
  top 行示例：`Lsat_8720838`（LSA15294，叶 sigmoid 0.990，score 0.720）。
- Demo 接线：新默认排序项"组织优先指数（目标组织）降序"，候选表增加优先指数列与表达证据列。

### 5.3 方案 6：橡胶草产胶时相窗口（`scripts/23`）

**难点：TKS 注释没有任何功能注解**（全部是 "EVM prediction"），SRPP/REF/CPT 三个产胶基因家族
只能靠同源识别。路径：

1. 参考序列获取：UniProt REST 与 NCBI 在本机网络均不可达（代理只放行部分域名），
   **EBI 可达** → 经 EBI Search 定 accession、EBI dbfetch 拉 9 条橡胶树（*Hevea*）参考蛋白
   （REF×3 / SRPP×3 / CPT×3）。
2. 翻译 TKS 全部 36,183 个 CDS；鸽笼式 5-mer 词预筛 + Smith-Waterman 验证
   （identity ≥0.30、coverage ≥0.50）。第一版用 7-mer/≥3 词时 REF/SRPP **一个成员都筛不出**
   （65% 一致性下 7-mer 精配概率仅 ~5%）——改 5-mer/step1/≥4 词后恢复。
3. 成员：SRPP 8 个（含 LG01.550–554 串联簇，identity 0.43–0.69）、REF 2 个
   （LG01.555/557）、CPT 4 个（含 LG01.6995/6999——恰是 Hi-TOM 训练集的同源对）。
4. 动力学：根 S1–S9、胶乳 S4–S9 家族均值 TPM，三次样条 + 一阶导数定爆发期。

**两个动力学定义缺陷的修复**：

- 样条导数在**端点**失真，曾把"爆发期"判到 S9（而峰值在 S4）；改为只在**主峰之前的上升段**取导数最大处。
- 胶乳曲线**峰值就在首个采样时相 S4/S5**（上升过程发生在采样开始前、不可观测），
  S8→S9 的小回升不得误判为主爆发期；此类情形判 `peak-at-first-sample`，推荐"不晚于 S4"。

**结论：三个家族统一推荐 S4 期（胶乳初生）启动诱导**，与计划文档示例卡一致；
根爆发期 S4–S7、根峰值 fold 2.0–6.4 作为辅证。产出 9 时相动态图（英文标签——matplotlib
默认字体无 CJK 字形）与 Tab 1 的时相决策组件。

### 5.4 方案 5：组织功能性脱靶危害（轻量版，`scripts/22`）

**完整版为什么做不了**：608 万位点底层大表与按染色体扫描参考**都已不在磁盘上**（只剩每 guide
的 mis 计数表）；且脱靶坐标在 T2T 体系、表达量在 v1.1c 体系，中间需要全基因组 liftover（见 §7 spike）。

**轻量版范围**：49 个面板基因座**之间**的 collateral 切割——这些是唯一有 crosswalk 背书表达值的区域。

- 位点发现：鸽笼 5-mer 种子筛（≤3 错配 ⇒ 4 块中必有一块精配）+ 双链 5-mer 索引 +
  NGG PAM 在**各链自身坐标系**内验证（minus 命中换算回 plus 坐标）+ Hamming ≤3 + 自身 on-target 排除。
- 危害式按计划文档：`Hazard_t(g) = Σ ω(mis)·[1 + 0.5·log2(TPM_t(LSA)+1)]`，
  ω = {0:10, 1:3, 2:1, 3:0.2}；unmappable 基因座按背景 0.1。
- 结果：**10,120 个面板内位点**（mis 阶梯 1164/2601/2909/3446）；14,575/19,839 条 guide
  危害为 0；P95 = 6.4；max = 166.9（`Lsat_10968423`，带 **13 个 mis0 完美旁系 collateral 位点**
  ——正是最该被重罚的那类 guide）。
- 2 个双峰基因座被 >300kb 守卫跳过、另有 1 个基因命中 guide 不足 3 条，均如实排除；46/49 扫描。
- Demo 接线：候选表按目标组织动态显示危害列 + 面板内位点数；产物缺失时优雅降级。

## 6. 方案 5 完整版可行性 spike：一次预注册的否证

### 6.1 什么叫 spike

限时可行性探针：用最小实验回答一个 yes/no 技术问题，再决定要不要投入完整开发。
本次预注册判据（**跑前定死，防止事后移动球门**）：

1. 查询覆盖率 ≥90%；2. 比对一致性 ≥95%；3. 共线性 ≥90%；
4. **guide 级地面真值 ≥80%**（已知真值的 guide 经 liftover 后落在其 crosswalk LSA 区间 ±10kb 内）。

### 6.2 链路（三个环境坑）

bioconda 与 conda-forge 的 win-64 均**没有** minimap2/mappy 包；pip 编译缺 MSVC；
最终用**官方 linux 二进制 + 项目既有的 WSL Ubuntu**（零新环境零编译）。
第一个坑：单条 258Mb 的 query 记录不被 minimap2 切分，per-record 内存爆炸 → **OOM exit 137**；
切 52 条 5Mb 片段（20kb 重叠）后 297 秒跑完、峰值 RSS 5.7GB。

### 6.3 结果：4 过 1，否证

| 判据 | 阈值 | 实测 | |
|---|---|---|---|
| 覆盖率 | ≥90% | 99.9% | PASS |
| 一致性 | ≥95% | 58.2% | FAIL |
| 共线性 | ≥90% | 41.9% | FAIL |
| guide 真值 | ≥80% | 0/20 | FAIL |

**失败机理（单 guide 诊断）**：含已知 guide 的比对块是 5Mb 尺度、块级一致性仅 80%；
块内线性插值把坐标 lift 偏了 **~65kb**，落进邻 gene `LSA25663`（真值在 LSA25641/25643 区）。
两个莴苣组装之间的分歧与块间重排，使 **block 级 liftover 原理上不具备碱基级精度**。
若未来重启完整版，前置是 CIGAR 级投影 + 重排断点处理。

**附带结论**：这个失败反向印证了 crosswalk 的设计——"逐基因座精确锚点 + 投票"在基因尺度上
恰好绕开全局 liftover 的弱点，这是它能做到 35/49 的原因。

## 7. 方案 4 降级：两条独立且各自充分的理由

1. **物种错配**：ρ≥0.50 达标线挂在**橡胶草 Hi-TOM 训练集**的 LOGO-CV 上；
   而 ATAC-seq 可及性与转录链冲突特征**只有莴苣有**——它们在训练集每一行上都算不出来，
   进不了被该指标评估的模型。
2. **方案2 已证伪 RNA 路径**：TKS 基因级表达协变量在 LOGO 折内是常数偏移，对折内 Spearman
   的直接贡献恒为 0（§4.1），且聚类自助 CI 全跨 0（§4.3）。

合起来：按原设计投入 1.5–2 天，会得到一个**多组学项对自己验收指标结构性零贡献**的模型。
决策：scripts/18–20 不实施；ATAC/链冲突特征改投莴苣侧重排与脱靶评估（方案3/5 线）；
ρ≥0.50 判据仅保留给未来"基因内可变特征"的尝试，且必须附带稳健性条件
（有效折数、逐折 IQR、Class A 中位 ρ、固定种子与 max_iter——由 §4.3 的翻转折教训导出）。
