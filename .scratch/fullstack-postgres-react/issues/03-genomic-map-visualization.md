# 03: 基因组靶点物理分布与 ECharts 交互图谱切片

**What to build:** 
为前端候选检索面板集成生信交互图谱。当科研人员选定基因后，界面通过 Apache ECharts 渲染出该基因染色体物理坐标轨线图（包含外显子结构高亮、正反链双轨分布以及按预测效率分渲染的热力渐变色）。支持框选缩放（DataZoom）、悬浮信息气泡，以及点击图表上的靶点锚点与下方候选大表对应行实现高亮联动。

**Blocked by:** 02: 49 基因候选数据自动灌库与多维检索切片

**Status:** ready-for-agent

- [ ] 前端引入并封装 `Apache ECharts`（`echarts-for-react`）组件

- [ ] 实现图表视口缩放（DataZoom）与自适应布局调整
- [ ] 实现图表锚点与候选数据表格行点击的双向聚焦高亮联动
