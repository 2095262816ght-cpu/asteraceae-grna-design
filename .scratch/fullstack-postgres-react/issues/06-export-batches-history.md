# 06: 实验设计导出批次与历史任务抽屉切片

**What to build:** 
打通实验决策成果固化与历史计算追溯。在候选靶点检索面板中，科研人员可以多选满意的 gRNA，一键命名并创建为「导出批次」，持久化保存在 `export_batches` 表中，并支持直接下载符合实验室下单规范的 CSV/Excel 表格。在打分工作台中，提供滑出式「历史任务抽屉」，列出过往所有打分作业（包含执行时间、条数、状态及模型来源），点击任意历史作业即可恢复该批次的完整结果视图。

**Blocked by:** 02: 49 基因候选数据自动灌库与多维检索切片, 05: 批量序列上传与异步轮询流水线切片

**Status:** completed

- [x] 后端暴露 `POST /api/v1/exports`（保存勾选靶点批次）与 `GET /api/v1/exports/{id}/download`（流式下载 CSV/Excel）
- [x] 后端暴露 `GET /api/v1/scoring/jobs`（支持按时间倒序获取任务历史列表）
- [x] 前端候选数据大表增加复选框列与悬浮导出操作栏，支持自定义批次名称并直接触发文件下载
